 프로젝트 파일 구조
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

src/
├── App.jsx                           ← 메인 앱 컴포넌트 (3열 레이아웃 + 드래그 앤 드롭)
├── main.jsx                          ← React 진입점
├── index.css                         ← Tailwind 설정 + 글로벌 스타일
│
├── components/
│   ├── common/
│   │   ├── DragHandle.jsx            ← 편집 모드 드래그 아이콘 (GripVertical)
│   │   ├── Toggle.jsx                ← 재사용 토글 스위치
│   │   └── WidgetCard.jsx            ← 위젯 공통 래퍼 (제목, 닫기, 새로고침)
│   │
│   ├── layout/
│   │   ├── FixedButtons.jsx          ← 하단 우측 플로팅 버튼 (편집/스마트위젯/설정)
│   │   ├── LoginScreen.jsx           ← 구글 OAuth + 데모 로그인 화면
│   │   ├── QuickLinks.jsx            ← 즐겨찾기 바로가기 (호버 시 펼침)
│   │   └── TopNav.jsx                ← 상단 헤더 (아바타/시계/검색/테마 토글)
│   │
│   ├── modals/
│   │   ├── BriefSettingsModal.jsx    ← AI 브리핑 톤/길이 설정
│   │   ├── OnboardingModal.jsx       ← 온보딩 (카테고리 + 권한 설정)
│   │   └── SettingsModal.jsx         ← 전체 설정 패널
│   │
│   └── widgets/
│       ├── AddSmartWidget.jsx        ← 스마트 위젯 추가 카드
│       ├── BriefingWidget.jsx        ← AI 브리핑 위젯
│       ├── CalendarWidget.jsx        ← 캘린더 (월/주/일 뷰)
│       ├── DiaryCard.jsx             ← 다이어리 질문 카드
│       ├── HealthWidget.jsx          ← 건강 (Google Fit) 위젯
│       ├── MiniWidgetGrid.jsx        ← 미니 위젯 2x2 요약 그리드
│       ├── SmartWidgetContent.jsx    ← AI 키워드 스마트 위젯
│       ├── StocksWidget.jsx          ← 주식/환율 위젯
│       ├── TodoWidget.jsx            ← 오늘의 할 일 위젯
│       ├── TrendsWidget.jsx          ← 실시간 트렌드 위젯
│       └── WeatherWidget.jsx         ← 날씨 위젯
│
├── constants/
│   └── index.js                      ← 카테고리, 위젯 목록, 기본 설정값
│
├── hooks/
│   └── useTheme.js                   ← 다크/라이트 테마 훅
│
├── lib/
│   └── supabase.js                   ← Supabase 클라이언트 초기화
│
├── mock/
│   └── data.js                       ← 모든 목 데이터 + 목 fetch 함수
│
├── services/
│   ├── aiService.js                  ← AI 브리핑 생성 + 스마트 위젯 (Edge Function)
│   ├── api.js                        ← REST API 헬퍼 (플레이스홀더)
│   └── googleService.js              ← Google OAuth/Fit/Calendar 스텁
│
├── store/
│   ├── useAuthStore.js               ← 인증 상태 (Supabase Google OAuth + 데모)
│   ├── useDataStore.js               ← 데이터 패칭 (날씨/주식/트렌드/맛집/캘린더/건강)
│   ├── useQuickLinksStore.js         ← 즐겨찾기 링크 CRUD (localStorage)
│   ├── useSettingsStore.js           ← 사용자 설정 (테마/시계/온도/주식/브리핑)
│   ├── useTodoStore.js               ← 할 일 CRUD + 일일 리셋 + Supabase 동기화
│   └── useWidgetStore.js             ← 위젯 가시성/레이아웃/스마트 키워드 관리
│
└── utils/
    ├── helpers.js                    ← D-day 계산 유틸
    └── storage.js                    ← localStorage load/save 래퍼

 기능별 코드 연결 관계
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1] 로그인 / 인증
    관련 파일: LoginScreen.jsx, useAuthStore.js, supabase.js
    동작:
      - Supabase 설정 시: 구글 OAuth 로그인 (Calendar + Fitness 스코프 포함)
      - Supabase 미설정 시: "데모 모드" 버튼으로 로컬 모드 진입
    사용법: 앱 첫 화면에서 "구글 계정으로 시작하기" 클릭

[2] 상단 헤더 (TopNav)
    관련 파일: TopNav.jsx, QuickLinks.jsx, useQuickLinksStore.js, useSettingsStore.js
    동작:
      - 왼쪽: 프로필 아바타
      - 중앙: 실시간 시계 (1초 갱신) + 구글 검색바
      - 오른쪽: 즐겨찾기 바로가기 + 다크/라이트 테마 토글
    사용법:
      - 검색바에 입력 후 Enter → 구글 검색 새 탭
      - 지구본 아이콘에 마우스 호버 → 즐겨찾기 링크 펼침
      - 점 3개(⋯) 클릭 → 링크 추가/삭제/편집
      - 달/해 아이콘 클릭 → 다크/라이트 모드 전환

[3] 위젯 레이아웃 + 드래그 앤 드롭
    관련 파일: App.jsx
    동작:
      - 3열 Flexbox 레이아웃 (왼쪽/중앙/오른쪽)
      - 모든 위젯은 드래그하여 같은 열 내 순서 변경 또는 다른 열로 이동 가능
      - 레이아웃은 localStorage에 자동 저장
    사용법: 위젯을 마우스로 잡고(grab) 드래그하여 원하는 위치에 놓기(drop)

[4] AI 브리핑
    관련 파일: BriefingWidget.jsx, aiService.js, useSettingsStore.js, mock/data.js
    동작:
      - 톤(친근/전문/유머) 설정에 따라 다른 브리핑 표시
      - Supabase 연결 시 Groq Edge Function으로 실시간 AI 브리핑 생성
      - 미연결 시 mockBriefings 데이터 사용
    사용법: 하단 설정(⚙) → 브리핑 설정에서 톤 변경

[5] 날씨
    관련 파일: WeatherWidget.jsx, useDataStore.js (fetchWeather)
    동작:
      - Groq LLM 기반 날씨 추정 또는 API 데이터
      - 온도 C/F 전환 가능
      - 상세: 습도, 강수, 대기질
    사용법: C/F 버튼으로 단위 전환, 새로고침 버튼으로 갱신

[6] 주식/환율
    관련 파일: StocksWidget.jsx, useDataStore.js (fetchStocks), useSettingsStore.js
    동작:
      - 기본 심볼: KOSPI, NASDAQ, S&P500, USD/KRW (최대 4개)
      - Twelve Data Edge Function으로 실시간 시세
      - 설정에서 심볼 변경 + 직접 입력(예: AAPL)
    사용법: 톱니바퀴(⚙) 클릭 → 심볼 선택/추가

[7] 실시간 트렌드
    관련 파일: TrendsWidget.jsx, useDataStore.js (fetchTrends)
    동작:
      - Tavily API로 실시간 뉴스/트렌드 검색
      - AI 요약 + 해시태그 + 출처 링크
    사용법: 새로고침 버튼으로 최신 트렌드 갱신, 출처 클릭으로 원문 이동

[8] 건강 (Google Fit)
    관련 파일: HealthWidget.jsx, useDataStore.js (fetchHealth)
    동작:
      - Google Fit 연동 시: 걸음 수, 수면, 심박수, 칼로리, 수분 섭취
      - 미연동 시: 목 데이터 표시
    사용법: 구글 로그인 시 Fitness 권한 승인하면 자동 연동

[9] 캘린더
    관련 파일: CalendarWidget.jsx, mock/data.js
    동작:
      - 3가지 뷰: 월간(기본), 주간, 일간
      - 오늘 날짜 파란색 하이라이트
      - 하단에 오늘 일정 표시
    사용법: 점 3개(⋮) → 일/주/월 뷰 전환, ◀▶로 월 이동

[10] 오늘의 할 일
    관련 파일: TodoWidget.jsx, useTodoStore.js
    동작:
      - 할 일 추가/완료 토글/삭제
      - "루틴" 할 일은 매일 리셋 (완료 해제, 삭제 안됨)
      - Supabase 연동 시 DB 동기화
    사용법: "+ 새 할 일 추가" 클릭, 체크박스로 완료 처리

[11] 다이어리 카드
    관련 파일: DiaryCard.jsx
    동작:
      - 하루 한 번 AI 질문에 답변 기록
      - 답변 저장 시 시간 + 내용 리스트로 표시
      - 카드 높이 고정, 내부 스크롤
    사용법: 텍스트 입력 후 "확인" 클릭으로 저장

[12] 미니 위젯 그리드
    관련 파일: MiniWidgetGrid.jsx, mock/data.js
    동작:
      - 날씨/증시/뉴스/할일 요약을 2x2 그리드로 표시
      - 목 데이터 기반 빠른 요약
    사용법: 한눈에 주요 정보 확인용 (클릭 불필요)

[13] 스마트 위젯 (AI 키워드)
    관련 파일: SmartWidgetContent.jsx, AddSmartWidget.jsx, useWidgetStore.js, aiService.js
    동작:
      - 사용자가 키워드 입력 → Groq + Tavily로 AI 분석
      - 요약/가격/트렌드/뉴스 섹션 자동 생성
      - 위젯 삭제/새로고침 가능
    사용법: 하단 우측 + 버튼 → 키워드 입력 → "추가"

[14] 즐겨찾기 바로가기 (QuickLinks)
    관련 파일: QuickLinks.jsx, useQuickLinksStore.js
    동작:
      - 기본: 네이버, 유튜브, 인스타그램, 구글
      - 지구본 아이콘에 마우스 호버 → 동그라미 아이콘들이 왼쪽으로 펼침
      - 점 3개 클릭 → 편집 팝업 (이름/URL/아이콘/색상 지정)
      - 추가한 링크 클릭 → 해당 사이트로 새 탭 열기
      - 마우스 떠나면 자동 접힘
    사용법: 우측 상단 지구본 아이콘 위에 마우스 올리기

[15] 하단 플로팅 버튼 (FixedButtons)
    관련 파일: FixedButtons.jsx, useWidgetStore.js, useSettingsStore.js
    동작:
      - 자물쇠 아이콘: 편집 모드 토글 (위젯 드래그 배치)
      - + 아이콘: 스마트 위젯 추가 (키워드 팝업)
      - 톱니바퀴 아이콘: 전체 설정 패널 열기
    사용법: 화면 우측 하단 버튼 클릭

[16] 설정 패널
    관련 파일: SettingsModal.jsx, BriefSettingsModal.jsx, useSettingsStore.js
    동작:
      - 위젯 표시/숨김 토글
      - 시계 스타일, 온도 단위, 주식 심볼 설정
      - 테마 변경, 프로필 관리
      - 브리핑 톤/길이 설정
    사용법: 하단 ⚙ 클릭 → 원하는 설정 변경

[17] 다크/라이트 모드
    관련 파일: useTheme.js, useSettingsStore.js, 각 컴포넌트
    동작:
      - 다크 모드: 회색 계열 배경(#1a1a1a) + 밝은 회색 카드(#2a2a2a) + 흰색 글씨
      - 라이트 모드: 밝은 그라디언트 배경 + 흰색 카드 + 어두운 글씨
      - 전환 시 300ms 부드러운 애니메이션
    사용법: 우측 상단 달/해 아이콘 클릭

 기술 스택
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- React 18 + Vite 6
- TailwindCSS 3 (유틸리티 CSS)
- Zustand 5 (상태 관리)
- Supabase (인증 + DB + Edge Functions)
- Lucide React (아이콘)

 개발 환경 실행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 의존성 설치: npm install
2. 개발 서버: npm run dev
3. 프로덕션 빌드: npm run build
4. (선택) Supabase 연동: .env 파일에 VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY 설정
