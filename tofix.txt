━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A. Auth bootstrap 완료 상태 추가
     - `authBootstrapDone` state 도입.
     - 인증 상태 확정 전에는 대시보드 대신 "세션 확인 중..." 화면 표시.

  B. 세션 복원 핸들링 강화
     - mount 시 `supabase.auth.getSession()` 명시 호출 유지.
     - `catch/finally` 추가로 실패 케이스에서도 상태를 확정.
     - `onAuthStateChange` 수신 시에도 bootstrap 완료 처리.

  C. 초기 로드 경로 이원화
     - 정상 경로: `user?.id` 존재 시 hydrate + fetchAll 실행.
     - fallback 경로: `isLoggedIn===true`인데 `user?.id`가 지연되면
       1.2초 후 `fetchAll({ useExistingCache:true })` 1회 실행.
     - `initPhaseRef`로 중복 초기화 방지.
