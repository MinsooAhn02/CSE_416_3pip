  - 좌/우 사이드바는 HUD 장식 (System Status, Protocol Log 등)

  - "왼쪽(AI Briefing) | 중앙(Widgets + Diary) | 오른쪽(Calendar)" 고정 3열
  - CSS Grid 또는 Flexbox 사용
  - 각 열에 특정 카드 고정 배치

충돌 사항:
  ★ react-grid-layout(드래그 가능 그리드) 방식 vs 고정 3열 레이아웃 — 근본적 충돌
  → react-grid-layout을 제거하거나 유지할지 결정 필요

방안 A: react-grid-layout 제거, 순수 CSS Grid 3열로 교체
  - 장점: 프롬프트 요구와 정확히 일치, 코드 단순화
  - 단점: 드래그 재배치, AutoHeight, editMode 등 기존 기능 전부 유실
  - 영향: useWidgetStore의 layouts/editMode/handleLayoutChange 등 무용화

방안 B: react-grid-layout 유지 + 기본 레이아웃만 3열 형태로 재설정
  - 장점: 기존 기능 유지, 향후 확장성
  - 단점: 프롬프트의 "고정 열" 개념과 맞지 않음, 복잡도 증가

★ 권장: 방안 A (react-grid-layout 제거, CSS Grid 3열)
  → 프롬프트가 "백엔드 연결 없이 깔끔한 디자인 + 기본 인터랙션" 위주라 더 적합

변경 파일: App.jsx (전면 재작성), useWidgetStore.js (단순화), constants/index.js (레이아웃 상수 제거)

  3. 잠재적 문제점 및 주의사항
================================================================================

[문제 1] 로그인 게이트와 "백엔드 없이" 충돌
  - 현재 isLoggedIn이 false면 LoginScreen만 렌더링
  - 프롬프트는 "백엔드 연결 없이" → 로그인 없이 대시보드 바로 표시해야 함
  - 해결: 로그인 게이트 우회 또는 항상 isLoggedIn=true 처리
  - 영향: Supabase auth, hydrate 로직 전부 스킵

[문제 2] useDataStore의 API 호출 로직
  - fetchAll, fetchWeather 등이 Edge Function 호출 → 실패 시 mock fallback
  - 프롬프트는 "백엔드 없이" → mock 데이터만 사용하도록 단순화 가능
  - 현재 mock fallback이 이미 있으므로, API 호출을 스킵하면 됨

[문제 3] Zustand 스토어 의존성
  - App.jsx가 6개 Zustand 스토어에 의존
  - 전면 재작성 시 사용하지 않는 스토어 import 정리 필요
  - useWidgetStore: vis, layouts, editMode 등 → 3열 고정이면 대부분 불필요
  - useAuthStore: 로그인 우회 시 최소한만 사용

[문제 4] Tailwind CSS config 미확장
  - tailwind.config.js에 커스텀 테마 확장이 없음
  - 프롬프트의 "깨끗하고 미니멀한 UI"에 맞는 커스텀 색상/간격은 Tailwind 기본으로 충분
  - 다만 transition 관련 커스텀이 필요할 수 있음

[문제 5] OIW CSS 변수 시스템과의 충돌
  - 일부 컴포넌트가 CSS 변수 (--color-primary 등) 사용 (TopNav 등)
  - 새 대시보드에서 이 시스템을 유지할지 Tailwind 순수로 갈지 결정 필요
  - 권장: Tailwind 순수 사용 (미니멀 + 다크/라이트 전환만 필요하므로)

[문제 6] react-grid-layout CSS import
  - index.css line 1: @import "react-grid-layout/css/styles.css"
  - 그리드 제거 시 이 import도 제거해야 불필요한 CSS 로딩 방지

[문제 7] 기존 localStorage 데이터
  - 기존 사용자의 localStorage에 mb_layouts, mb_vis 등 저장된 데이터
  - 레이아웃 구조가 완전히 바뀌므로 LAYOUT_VERSION 업데이트 or 키 변경 필요
