■ 1. 애니메이션 및 레이아웃 (형제 노드 + 오버레이 방식)
--------------------------------------------------------------------------------

[확정] 동작 방식:
  - 위젯 클릭 시 isExpanded = true
  - 원래 위젯은 그 자리에 그대로 유지
  - 상세 창은 위젯 위에 오버레이로 나타남
  - 애니메이션: scale(0.5 → 1) + opacity(0 → 1) 로 중앙 확장

[구현 상세]
  - framer-motion: AnimatePresence + motion.div 사용
  - initial: { opacity: 0, scale: 0.5 }
  - animate: { opacity: 1, scale: 1 }
  - exit: { opacity: 0, scale: 0.5 }
  - transition: spring 또는 tween (duration: 0.3s 권장)

[Z-Index 관리]
  - 배경 오버레이: z-[60]
  - 상세 창 본체: z-[61] 이상


■ 2. 스크롤 제어 (Layout Shift 방지)
--------------------------------------------------------------------------------

[useEffect 로직]
  ```javascript
  useEffect(() => {
    if (isExpanded) {
      const scrollbarWidth = window.innerWidth - document.documentElement.clientWidth;
      document.body.style.overflow = 'hidden';
      document.body.style.paddingRight = `${scrollbarWidth}px`;
    }
    return () => {
      document.body.style.overflow = '';
      document.body.style.paddingRight = '';
    };
  }, [isExpanded]);
  ```

[상세 창 내부]
  - 콘텐츠 영역에 overflow-y-auto 적용
  - max-h-[70vh] 또는 적절한 높이 제한


■ 3. AI 로직 및 데이터 연동 (aiService.js)
--------------------------------------------------------------------------------

[새 함수: generateDetailedBriefing]
  - Single API Call로 summary + detail 동시 반환
  - 반환 형식: { "summary": "3줄 요약", "detail": "10~15줄 상세" }

[calEvents 전처리]
  - AI 전달 전 가독성 높은 문자열로 변환
  - 예: "10:00 팀 회의, 14:00 고객 미팅, 16:30 스크럼"
  - 시간순 정렬 필수

[데이터 호출 시점 - 하이브리드 방식]
  1. 위젯 최초 마운트 시: 1회 AI 호출 → 캐시 저장
  2. 상세 창 열림 시: 캐시된 데이터 즉시 표시
  3. 새로고침 버튼: 새로운 AI 호출 → 캐시 갱신
  4. 캐시 유효시간: 세션 동안 유지 (또는 5분)

[로딩 상태 UI]
  - 스켈레톤 문단 (3~4줄 회색 블록)
  - 페이드 인/아웃 애니메이션
  - Tailwind: bg-gray-200 dark:bg-gray-700 animate-pulse

```javascript
// 캘린더 이벤트 포맷팅
export function formatCalEventsForAI(calEvents = []) {
  return calEvents
    .sort((a, b) => new Date(a.start) - new Date(b.start))
    .map(e => {
      const time = new Date(e.start).toLocaleTimeString('ko-KR', { 
        hour: '2-digit', minute: '2-digit', hour12: false 
      });
      return `${time} ${e.title || e.summary}`;
    })
    .join(', ');
}
```

```jsx
const BriefingWidget = () => {
  const [isExpanded, setIsExpanded] = useState(false);
  const [detailedBriefing, setDetailedBriefing] = useState(null);
  const [isLoading, setIsLoading] = useState(false);
  
  // 스크롤 잠금
  useEffect(() => {
    if (isExpanded) {
      const scrollbarWidth = window.innerWidth - document.documentElement.clientWidth;
      document.body.style.overflow = 'hidden';
      document.body.style.paddingRight = `${scrollbarWidth}px`;
    }
    return () => {
      document.body.style.overflow = '';
      document.body.style.paddingRight = '';
    };
  }, [isExpanded]);

  return (
    <>
      {/* 기존 위젯 카드 - 클릭 시 확장 */}
      <div onClick={() => setIsExpanded(true)} className="cursor-pointer ...">
        {/* 위젯 내용 (summary 표시) */}
      </div>

      {/* 상세 창 - AnimatePresence */}
      <AnimatePresence>
        {isExpanded && (
          <>
            {/* 배경 오버레이 */}
            <motion.div 
              className="fixed inset-0 z-[60] bg-black/50 backdrop-blur-md"
              onClick={() => setIsExpanded(false)}
              initial={{ opacity: 0 }}
              animate={{ opacity: 1 }}
              exit={{ opacity: 0 }}
            />
            
            {/* 상세 창 본체 */}
            <motion.div
              className="fixed top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 z-[61] ..."
              initial={{ opacity: 0, scale: 0.5 }}
              animate={{ opacity: 1, scale: 1 }}
              exit={{ opacity: 0, scale: 0.5 }}
            >
              {/* 헤더: 인사말 + X */}
              {/* 콘텐츠: detail 텍스트 */}
            </motion.div>
          </>
        )}
      </AnimatePresence>
    </>
  );
};
```
