━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

핵심 원리:
  Δt = 현재 시간 - 마지막 접속 시간 (mb_last_access_time)
  Δt > 30분 → 캐시 stale → 전체 API 재호출
  Δt ≤ 30분 → 캐시 fresh → DB/localStorage 캐시 사용
  🔄 수동 새로고침 → force=true로 30분 제한 무시

캐시 저장:
  1순위: api_cache 테이블 (Supabase DB, 사용자별 영구)
  2순위: localStorage mb_cache_* (즉시 접근용 fallback)

캐시 키 예시:
  weather_37.5665_126.978 / stocks_KOSPI_NASDAQ_SP500_USDKRW
  trends_default / calendar_today / health_default / restaurants_맛집_37.5665_126.978

데이터 로딩 순서:
  1) fetchAll() 호출 (로그인 후 App.jsx useEffect)
  2) isCacheStale() 체크 → shouldForceRefresh 결정
  3) force=false → readApiCache() → 캐시 hit 시 사용
     force=true  → Edge Function 직접 호출
  4) 응답 → normalize → set(state) + cacheIt(localStorage) + writeApiCache(DB)
  5) setLastAccessTime() 갱신

# 환경변수 로드
$envMap = @{}
Get-Content .env | Where-Object { $_ -match '^[A-Za-z_][A-Za-z0-9_]*=' } |
  ForEach-Object { $k,$v = $_.Split('=',2); $envMap[$k]=$v }
$base = "$($envMap.VITE_SUPABASE_URL)/functions/v1"
$key = $envMap.VITE_SUPABASE_ANON_KEY
$headers = @{ apikey=$key; Authorization="Bearer $key"; 'Content-Type'='application/json' }

# Groq (날씨용)
Invoke-RestMethod -Method Post -Uri "$base/groq" -Headers $headers -Body '{"system":"너는 날씨 정보 생성기다. 반드시 JSON 객체만 반환하고 다른 텍스트를 포함하지 마라.","prompt":"lat=37.5665, lon=126.978 기준 현실적 현재 날씨 추정 JSON. 키: temp, city, condition, precipitation, airQuality, humidity","temperature":0.2}'
# 판정: text 필드 안에 JSON 파싱 가능 → OK

# Groq (일반)
Invoke-RestMethod -Method Post -Uri "$base/groq" -Headers $headers -Body '{"prompt":"오늘 날짜를 한국어로 알려줘. 한 줄로.","temperature":0.3}'
# 판정: text에 한국어 날짜 응답 → OK

# Stocks
Invoke-RestMethod -Method Post -Uri "$base/stocks" -Headers $headers -Body '{"symbols":["KOSPI","NASDAQ","SP500","USDKRW"]}'
# 판정: price > 0 항목 존재 → OK / 전부 0 → TwelveData 한도 초과

# Tavily
Invoke-RestMethod -Method Post -Uri "$base/tavily" -Headers $headers -Body '{"query":"대한민국 실시간 이슈 트렌드"}'
# 판정: trends 배열 + answer 문자열 존재 → OK

# Kakao Places
Invoke-RestMethod -Method Post -Uri "$base/kakao-places" -Headers $headers -Body '{"query":"맛집","lat":37.5665,"lon":126.978,"radius":1200}'
# 판정: name/category/distance 키 존재 → OK

# Calendar (Google OAuth token 필요)
Invoke-RestMethod -Method Post -Uri "$base/calendar" -Headers $headers -Body '{"token":"GOOGLE_OAUTH_TOKEN_HERE","todayOnly":true}'
# 판정: title/start 키 존재 → OK / 401 → token 만료, 재로그인

# 판정: steps/sleep/calories 키 존재 → OK / note에 "no data" → 정상(데이터 없음)

# Smart Widget
Invoke-RestMethod -Method Post -Uri "$base/smart-widget" -Headers $headers -Body '{"keyword":"AI 뉴스"}'
# 판정: 요약 텍스트 존재 → OK / 에러 → GROQ + TAVILY 키 모두 확인
