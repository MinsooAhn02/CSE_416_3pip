프롬프트 요구:
  flex-1(브리핑) : flex-1(위젯/다이어리) : flex-[2](캘린더)

비율 구현 방법 비교:
  방법 A: flex-1 / flex-1 / flex-[2]
    → 장점: 프롬프트 문구("Flexbox 기반")와 일치
    → 단점: flex-[2]는 Tailwind JIT arbitrary value, 내용물 크기에 따라
             비율이 미세하게 흔들릴 수 있음
    → 보완: min-w-0을 각 열에 추가하면 overflow로 인한 비율 깨짐 방지

  방법 B: CSS Grid → grid-cols-4, col-span-1 / col-span-1 / col-span-2
    → 장점: 비율이 정확하게 보장, 캘린더 컨테이너 크기 고정 요구사항에 적합
    → 단점: 프롬프트가 "Flexbox"라 했으므로 의도에 어긋날 수 있음

  ★ 권장: 방법 A (Flexbox) + min-w-0 보완
    → 프롬프트 의도 존중, 실용적으로 문제 없음
